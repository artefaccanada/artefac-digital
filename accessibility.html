Accessibility Statement

Compliance Status

artefac.digital is working toward conformance with WCAG 2.1 Level AA. Several success criteria have been implemented; known gaps are documented below and are being addressed.

Our commitment

artefac INC is committed to ensuring that artefac.digital is accessible to as many people as possible, including those using assistive technologies such as screen readers, keyboard navigation, voice control, and display magnification. We take accessibility seriously not because of checkbox compliance, but because exclusion is a poor foundation for any technology company — and because Canadian government procurement increasingly requires it.

Measures implemented

The following measures have been applied to the current version of the site:

  • Skip navigation link — a "Skip to main content" link is the first focusable element on every page, allowing keyboard users to bypass repeated navigation.
  • Semantic HTML landmarks — <nav>, <main>, <footer>, and <section> elements are used to provide document structure readable by screen readers.
  • ARIA labels — all navigation regions, interactive controls, and social media links carry descriptive aria-label attributes. Decorative icons are marked aria-hidden="true".
  • Keyboard accessibility — all interactive elements (links, buttons, the mobile hamburger menu) are reachable and operable by keyboard alone. The mobile menu manages focus correctly on open and close, and traps focus within the overlay.
  • Visible focus styles — all focusable elements have a visible :focus-visible outline (3px, #2D6B4A) that meets the WCAG 2.2 focus appearance requirements. The navigation CTA uses a high-contrast gold outline on the dark background.
  • Colour contrast — foreground/background combinations have been audited. Body text (#3A3A3A on white) meets 10:1; muted text (#6B6B6B on white) meets 5.9:1; white text on the dark-green government section meets minimum 4.5:1 AA at all opacity levels used.
  • Reduced motion — a @media (prefers-reduced-motion: reduce) block disables all CSS transitions and scroll animations for users who have indicated this preference in their OS settings.
  • Responsive layout — the page reflows correctly at 320 px width and at 400% browser zoom without horizontal scrolling, meeting WCAG 1.4.10 (Reflow).
  • Language declaration — lang="en" is set on the <html> element of every page.
  • Link purpose — all links that open in a new tab include an aria-label noting "(opens in new tab)".
  • No auto-play media — the site contains no auto-playing audio or video.

Known limitations

The following issues have been identified and are scheduled for resolution:

  • Emoji in body text — several emoji characters are used in headings and body copy without role="img" or aria-label overrides. Screen readers will announce them by their Unicode name, which may be verbose or confusing. Fix planned: wrap decorative emoji in <span aria-hidden="true">.
  • Mobile hamburger menu — escape key — the Escape key does not yet close the mobile navigation menu and return focus to the trigger button. Fix in progress.
  • Third-party embeds — any future third-party embeds (forms, calendars, chat widgets) may introduce accessibility gaps outside our direct control. Each will be evaluated before deployment.
  • No formal VPAT or audit on file — a full third-party WCAG audit has not yet been conducted. One is planned for Q1 2027 in preparation for government tender submissions.

Technical approach

Accessibility on this site is implemented directly in the underlying HTML, CSS, and JavaScript. We do not use third-party overlay or widget products that claim to retrofit accessibility post-hoc. Overlays cannot substitute for properly structured markup and are not accepted as evidence of conformance by the Canadian government's Standard on Web Accessibility or the W3C's WCAG 2.1 specification.

Standards referenced

  • Standard on Web Accessibility, Treasury Board of Canada Secretariat
  • Accessibility for Ontarians with Disabilities Act (AODA) — Integrated Accessibility Standards Regulation
